# The Canopy

The Canopy is a recharge-focused coworking space concept designed for people who want a flexible place to work, meet, read, eat, create, and rest.

This repository contains the first version of The Canopy website. It is a responsive static frontend inspired by calm, nature-led interiors and modern editorial design.

## Current Features

- Responsive landing page for desktop, tablet, and mobile
- Canopy brand identity with a tree-inspired logo
- Hero section introducing the recharge hub
- Space categories for Lounge & Cafe, Relax, Focus, and Pantry
- Journey timeline showing the space development process
- Reasons-to-visit section for focus, connection, creativity, and recharge
- Opening updates email form with local frontend feedback
- Mobile navigation menu

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Unsplash image assets
- Firebase planned for the backend

## Run Locally

From the project directory, start a local web server:

```powershell
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```

## Planned Features

The next versions will extend the website into an interactive coworking platform with Firebase as the backend.

- User registration and authentication
- Membership and profile management
- Space and desk booking
- Booking availability and reservation management
- Group chat for Canopy members
- Community groups and event conversations
- Firebase database integration for opening updates and bookings
- Admin tools for spaces, members, bookings, and announcements

## Project Status

The project is currently in the first visual prototype stage. The public website and UI foundation are in place. Firebase services, booking workflows, and group chat will be added in future development phases.
